STEP 1 — TEST LEDGER. Complete this before anything else. You may not write the
word COVERED, PASS, or FIRST-RUN-SAFE anywhere above it.

For EVERY test named in [PLAN'S TEST CHANGES], output one row:

| # | test name (verbatim) | every argument the test constructs, verbatim | which branch those arguments actually reach | does the reached branch match the name? YES / NO / CANNOT TELL |

Rules for the ledger:
- Copy arguments verbatim from the input. Do not summarise them and do not
  substitute what the argument "would be" — if the input does not state a
  value, write UNSTATED.
- The "branch reached" column must follow from the arguments you just copied,
  not from the test's name. A name is a claim; the arguments are the evidence.
- Answer NO whenever the arguments cannot reach the branch the name claims, and
  CANNOT TELL whenever the input does not give you enough to decide. Both are
  acceptable answers. Guessing is not.
- Every test in the input gets a row, including ones you consider trivial.

STEP 2 — Only after the ledger is complete, continue with the review below.
Where the ledger says NO or CANNOT TELL for a test, the seam that test is meant
to cover cannot be called COVERED on the strength of that test.
