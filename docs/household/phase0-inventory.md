# Phase 0: household inventory (template)

The first step of [household-assistant.md](../household-assistant.md). **No software.** Each of you fills in a copy, then
merge the two. **Keep the filled-in copy out of the repo.** It is the household's own data. Save it as
`phase0-inventory-filled.md`, which git ignores (`.gitignore` → `*-filled.md`), or keep it outside the checkout entirely.

These lists become two things:
- what the tracker gets loaded with (phase 1);
- the test set every later phase is checked against ("done" means these get correct answers).

Rough is fine. A blank "last done" is useful information too.
