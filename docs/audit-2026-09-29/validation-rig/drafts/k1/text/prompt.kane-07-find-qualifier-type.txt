You are working in the KaneEnabler repository: a Commander (EDH) deck recommender whose server reads each card's oracle text and tags it with archetype signals, some of which carry a creature-type qualifier (for example Reanimator (Sliver)). In apps/commander-recommender/server/src/services/signals.ts, findQualifier(facts, def, vocab) works out that qualifier for an archetype whose payoff can be restricted to one creature type: it walks the card text clause by clause and, in the first clause where one of the archetype's payoff patterns (its rewards and consumes matchers) matches, returns a creature type from that clause. There is a bug: it returns the FIRST creature-type word found anywhere in the clause, whether or not that word has anything to do with what the pattern actually matched. Angel of Glory's Rise reads 'When this creature enters, exile all Zombies, then return all Human creature cards from your graveyard to the battlefield.' It is a Human reanimator, but its signal comes out as Reanimator (Zombie), because 'Zombies', which are merely exiled, come before 'Human', the thing actually returned, in the same clause. Fix findQualifier so the qualifier is the type the payoff actually restricts (here, the Humans being returned), not whichever type word happens to come first in the clause. Required behaviour: (1) Angel of Glory's Rise (type line 'Creature - Angel', with Zombie, Human and Angel in the creature-type vocabulary) yields a reanimator signal qualified 'Human' and no reanimator signal qualified 'Zombie'; (2) Sliver Gravemother ('Each Sliver creature card in your graveyard has encore {X}, where X is its mana value.') must still be Reanimator (Sliver), and every other existing test in the file must keep passing; (3) an unrestricted reanimator ('Return target creature card from your graveyard to the battlefield.') stays unqualified. Add a test in signals.test.ts for the Angel of Glory's Rise case; the file already has the helpers makeCard(overrides), signalsFor(card, creatureTypes?, keywords?), find(signals, archetype, qualifier?) and rolesOf(signals, archetype, qualifier?).
