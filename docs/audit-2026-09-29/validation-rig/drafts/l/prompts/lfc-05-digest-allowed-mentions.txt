You are working in the lfc-bot repository: a Discord bot for trading Magic: The Gathering cards that posts a daily listing digest. In src/services/digest.ts, runDigest builds one text message (formatDigest, whose lines come from digestLine in src/utils/embeds.ts) and delivers it with deliverToChannel (channel.send) and/or deliverToDm (user.send), depending on the server's digest mode. There is a security bug: every listing line carries '@' plus the listing author's Discord display name, which the author controls, and both sends pass the digest as a bare string. A member whose display name is 'everyone' (or 'here') therefore puts a literal '@everyone' into the digest, and because the send call tells Discord nothing about mentions, Discord's default mention parsing treats that text as a real mention and can notify the whole channel. The cause is in digest.ts: neither send restricts mention parsing for text the bot does not control. Fix digest.ts so that: (1) the channel send and the DM send each pass an options object instead of a bare string - the digest text as 'content' and an 'allowedMentions' option whose value is exactly { parse: [] } (an empty parse list, no other keys inside it), so nothing in the text can ping anyone; (2) the digest text itself is not altered - formatDigest and digestLine stay as they are, and names are still shown as written, they just cannot ping; (3) retries, the watermark rules and the returned DigestResult stay exactly as they are, so the existing tests in tests/services/digest.test.ts keep passing. Add or update tests in tests/services/digest.test.ts proving: the channel send is called with an options object containing allowedMentions { parse: [] } (the file already has fakeClientWithChannelSend, which hands your mock to channel.send, and an addListing helper); and the DM send gets the same option (this needs a server row with digestMode 'dm' and a digestDmUserId, and a fake client whose users.fetch resolves to an object with a send mock). Your added/updated tests must FAIL if only your digest.ts fix is reverted while the test changes stay. Change ONLY these two files: src/services/digest.ts and tests/services/digest.test.ts. Do not commit. Do not touch any other file. When done, run `npx vitest run tests/services/digest.test.ts` and make sure it passes.
