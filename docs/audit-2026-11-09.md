# Audit of 2026-11-09: findings, what was fixed, what is open

The record of a read-only audit of this repo (project, method, roadmap, docs) and of the work that followed it,
2026-11-09 to 2026-11-13. Written 2026-11-16 so the session that did it can be closed. The open items are also at
the top of [roadmap.md](roadmap.md). Terms: [glossary](glossary.md).

**Who did it.** A Claude session, with nine Haiku subagents doing the reading. Each subagent finding was checked
against the source before it was kept; three were dropped or corrected (below). Like the earlier reviews this is a
model reading work a model helped build ([methodology-caveats.md](methodology-caveats.md) → "Who checked what").
The owner's verdicts on real work are still the first independent check.

## The verdict

The measurement side is sound and honest about its limits. It has outrun the thing it measures. The main seat is
proven (45 of 48 on 16 tasks), 49 pull requests merged in the ten days before the audit, almost all harness, guards
and audits, and milestone 5, "first real use", was not reached. Every item on the roadmap's list was waiting on the
owner, not on a measurement.

**What held when rechecked:** all 16 Wilson intervals in [methodology.md](methodology.md), the sign tests of the
2026-11-07 audit, the runs-needed table (as arithmetic), and the hosted-seat 47 of 49 from
`tests/results/real-tasks-public.tsv`.

## Open: the owner's steps

In the order they are worth doing.

1. **Apply the firewall rule on the server** (`sudo`). Runbook: [network-topology.md](network-topology.md) → "Limit
   the model ports to named hosts", with three checks from the LAN and one for IPv6. Until then 8090 and 11434 are
   open to the whole LAN.
2. **Keep a copy of `WEBUI_SECRET_KEY`** off the server. Without it a restored chat cannot read its stored settings.
3. **Pull `main` on the server**, so the nightly backup includes the chat. The next morning `~/backups/household/backup.log`
   should show two `backup:` lines.
4. **`pwsh -File tests\run-window.ps1 -Plan` on the desktop**, once: it shows what the new "GPU to itself" gate reads
   from the real router, and changes nothing. The gate was tested against a stand-in only.
5. **`summarize-rounds.ps1` on a recent private round, with and without `-ExcludeTimeouts`**: how far the headline
   rounds move now that a timeout is a failure.
6. **The pilot on real work**: 3 to 5 tasks in the owner's own words, one of them the KaneEnabler validator holes,
   each ending in a verdict (`tests/new-real-task.ps1`, `tests/deliver-attempt.ps1`, `tests/record-verdict.ps1`). On
   today's setup, before the container changes the run environment.
7. Still open from the roadmap's list of 2026-11-07: the owner's edit of the local done lists (item 1), and the
   check of each planner set before use (item 2).

## Smaller findings, not acted on

Recorded so they are not found twice. None was judged urgent.

- **Reproducibility.** No seed is pinned (temperatures are set in `server/llamacpp/models.ini`). The public raw
  results stop at 2026-10-13: every November headline can only be re-derived from the private repo.
- **Contamination and holdout** are still unchecked (already in `methodology-caveats.md`).
- **`docs/main-seat-trial.md`**: twelve cells were planned, seven rows are in the table and four are listed as not
  run. `qwen3.5:9b` on task 3 is in neither. The verdict does not depend on it.
- **`tests/results/README.md`** says "107 recorded rows"; one subagent's count gave 100. Not re-derived.
- **Two older standings** (`qwen3:14b` 2 of 13, `qwen3.5` 13 of 21) use denominators a subagent could not
  reproduce strictly. Not re-derived; both tables are superseded.
- **Supply chain.** `.claude/hooks/session-start.sh` downloaded PowerShell with no checksum. **Fixed 2026-11-24:** it now unpacks only a tarball whose sha256 is the pin for its architecture (guard `tests/test-session-start-hook.ps1`). The Ollama, Grocy and
  Open WebUI images are pinned by tag, not digest. GitHub Actions are pinned by tag.
- **Operations.** No alert when a backup fails (it only writes a log). No off-site copy. The server does not
  disable ssh password login in the files this repo can see.
- **`opencode/agents` and `opencode/commands`** still carry Vercel and Render imports that are staged into every
  session (**deleted 2026-11-25**, owner's call; the live copies are the owner's to remove, `opencode/README.md`); `skills/` is 12 MB, of which two sets (`frontend-design`, `ui-ux-pro-max`) deploy globally.
